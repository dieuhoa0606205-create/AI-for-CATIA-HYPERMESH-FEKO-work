# CATIA → FEKO 工作流的用户侧提示词

执行方已经加载 [完整工作流提示词](../PROMPTS/catia-feko-workflow.md) 时，用户只需说明任务与输入。下面这段可直接复制，替换尖括号内容。

```text
把这个 CATIA 文件导入 HyperMesh，完成面网格几何清理和面网格划分，按材料对与面边界条件分组，导出 FEKO 可读的 .fhm。

文件：<项目编号>/<CATIA 文件名>
材料映射：<曲面编号→材料名>
面属性：<PEC 编号>；其余 <DB 或其他>
单元尺寸：<最终网格尺寸>；参考网格尺寸：<可选>
导出名：<文件名.fhm>
预先排除的面：<编号；没有就写“无”>

需要我决定的地方停下来问：是否先判定材料属性、配对表是否确认、重叠面每组删哪些。不要替我选，确认前不要改几何。开始生产前提醒我保存模型。
```

## 说明

- 去重、重叠检查、缝合、逐面计数与分组由执行方按完整提示词处理，用户不必逐项交代。
- `overlap_delete_ids` 在 `produce` 阶段由操作者从重叠报告中选定；空列表表示全部保留。
- 材料映射必须覆盖全部带材料曲面，包括重复面与后续要删除的面。
